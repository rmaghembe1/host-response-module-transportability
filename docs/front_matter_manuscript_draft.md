## Data availability statement

This study reanalysed publicly available transcriptomic datasets. The discovery analysis used GSE211567, and the formal external projection analysis used GSE73461. Additional candidate or technical-rehearsal datasets were audited as documented in the project repository. All dataset accession numbers, cohort-lock decisions, analysis boundaries and interpretation safeguards are recorded in the decision log and supporting audit files.

## Code availability statement

Analysis scripts, decision logs, audit outputs, manuscript-facing tables and figure-generation scripts are organized in the project repository. The workflow includes scripted differential-expression analysis, site-aware concordance assessment, module locking, projection-ready scoring inputs, fixed-module external projection, sensitivity analysis, figure export and manuscript package audits. Manuscript-facing figures were exported as 1800 dpi PNG, editable SVG and vector PDF.
