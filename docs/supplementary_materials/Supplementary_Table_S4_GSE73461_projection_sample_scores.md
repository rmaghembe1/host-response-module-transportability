# Supplementary Table S4. GSE73461 fixed-module projection sample scores

This supplementary table set provides sample-level fixed-module projection scores for GSE73461. Scores were generated using the locked GSE211567 module definitions and a pre-specified unweighted mean z-score rule. These scores support the primary DefiniteBacterial-versus-DefiniteViral external projection analysis and secondary context involving Control samples.
