# Live-Verified Hybrid / No-APC Guideline Audit

## Purpose

This document updates the financial-first journal screen using live publisher/guideline checks. Financial feasibility remains the first gate because the manuscript has no APC funding and all planned authors are Tanzania-based.

## Key verified finding

The strongest financial-first candidates are journals that permit subscription/non-open-access publication without an APC. Based on live checks, Elsevier hybrid/subscription journals are particularly important because they can offer a no-publication-fee subscription route while leaving open access optional.

4. Immunology — promising immunology option if subscription route and no author charges are confirmed.
