# Publication Figure Export Standard

All manuscript-facing figures must be exported in three formats:

1. PNG at 1800 dpi
2. Editable SVG
3. Vector PDF

The SVG file is the editable master, the PDF is the vector backup, and the 1800 dpi PNG is the high-resolution raster submission backup.

This standard applies to all main figures and supplementary figures intended for manuscript use. Lower-resolution exploratory figures may remain in intermediate results folders, but manuscript-facing figures must use this standard.
