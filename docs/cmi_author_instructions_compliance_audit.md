# CMI Author Instructions Compliance Audit

## Purpose

This document audits the CMI-facing manuscript package against the uploaded historical CMI Instructions for Authors and the current ScienceDirect/Elsevier CMI author guidance. It identifies which requirements are already satisfied and which changes are still needed before journal-format conversion and submission.

## Source hierarchy

### Current authoritative source

The current ScienceDirect/Elsevier CMI Guide for Authors should be treated as the primary formatting authority for submission preparation.

### Historical uploaded source

The uploaded PDF titled `PIIS1198743X14652228.pdf` is an older CMI Instructions for Authors document. It is useful for historical comparison and for persistent general principles such as Vancouver references, cover-letter declarations and table/figure separation, but it contains outdated submission mechanics such as paper triplicate copies, diskette submission and fax details. It should not override current online CMI guidance.

## Current CMI article type assessment

Recommended article type:

- Original Article

Rationale:

- The manuscript presents original secondary analysis of public transcriptomic datasets.
- It includes a defined discovery/projection design, external cohort projection, quantitative module-level results and sensitivity analysis.
- It is not a Review, Commentary, Research Note or Brief Technical Report.
