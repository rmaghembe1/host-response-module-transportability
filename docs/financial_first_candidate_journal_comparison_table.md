# Financial-First Candidate Journal Comparison Table

## Purpose

This table supersedes the earlier scope-first journal ranking. It ranks candidate journals by financial feasibility first, using the current author profile: all planned authors are Tanzania-based, and Reuben S. Maghembe is the first and corresponding author.

## Current financial logic

The safest journals are hybrid/subscription journals that allow standard publication without APC. Fully open-access journals are practical only if a 100% APC waiver or institutional/publisher coverage can be confirmed before submission.

## Revised preferred order

1. First audit hybrid/subscription journals with no mandatory APC: Clinical Microbiology and Infection, Diagnostic Microbiology and Infectious Disease, Journal of Microbiological Methods, and other suitable hybrid/subscription options.
2. Only then audit fully open-access journals with possible waiver routes: BMC Genomics, BMC Medical Genomics, Frontiers in Immunology, Scientific Reports and Infection, Genetics and Evolution.
3. Do not commit to any fully open-access journal until a full waiver or APC coverage route is verified.

## Immediate next action

Perform a focused no-APC/hybrid target audit, beginning with Clinical Microbiology and Infection, Diagnostic Microbiology and Infectious Disease, Journal of Microbiological Methods, Methods, and additional Elsevier/Society hybrid journals relevant to infection transcriptomics, systems immunology, microbiology and computational biology.

## Interpretation boundary

Financial-first journal selection does not change the manuscript's scientific framing. The manuscript remains a fixed-module transportability analysis of host-response programmes, not diagnostic classifier discovery, diagnostic model validation, gene rediscovery, module redefinition or causal validation.
