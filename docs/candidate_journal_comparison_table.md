# Candidate Journal Comparison Table

## Purpose

This table provides a first-pass journal-targeting comparison for the current audited manuscript draft v0.4. It should be updated after checking each journal's current author guidelines, article types, word limits, figure requirements, APCs, and data/code policies.

## Current preferred target tier

The strongest initial targets are **BMC Genomics**, **BMC Medical Genomics**, and **Frontiers in Immunology — Systems Immunology**, because the manuscript is a reproducible host-transcriptomic module-transportability study rather than a clinical diagnostic classifier paper.

## Recommended next step

Perform a formal journal-guideline audit for the top three candidate journals before committing to formatting. The audit should verify article type, word limits, abstract structure, figure limits, supplementary-file policy, reference style, data/code policy and publication costs.

## Interpretation boundary

Journal positioning must preserve the fixed-module transportability framing. The manuscript should not be presented as diagnostic classifier discovery, diagnostic model validation, clinical diagnostic test development, gene rediscovery, module redefinition or causal validation.
