# Formal External Projection Candidate Search Plan

## Purpose

This document defines the next search step for identifying an independent formal external projection cohort for locked GSE211567 discovery modules.

## Current status

- GSE211567 is the locked discovery cohort.
- GSE161731 is restricted to technical scoring rehearsal only.
- GSE261482 was audited and is not eligible for primary bacterial-versus-viral projection because viral/pathogen-class labels were not recovered.
- A stronger formal external projection cohort is still required.

## Required cohort properties

A primary formal external projection cohort should ideally include:

1. Human host transcriptome data from whole blood, peripheral blood, PBMC or a closely comparable immune compartment.
2. Independent samples not used in GSE211567 module discovery.
3. Clear bacterial and viral infection labels at sample level.
4. Expression matrix available as gene-level counts, normalized RNA-seq, microarray expression or mappable identifiers.
5. Sufficient sample size in bacterial and viral groups.
6. Metadata adequate for transparent inclusion/exclusion.
7. No need to redefine, rename or reweight locked GSE211567 modules.

## Priority candidate types

Priority should be given to:

1. Adult or mixed-age acute infection cohorts with bacterial and viral groups.
2. Respiratory or febrile illness cohorts with confirmed pathogen-class labels.
3. Blood RNA-seq cohorts with recoverable gene identifiers.
4. Cohorts with public processed matrices and clear sample annotations.

## Search terms to use

Candidate searches should combine:

- bacterial viral infection blood transcriptome RNA-seq GEO
- bacterial versus viral host transcriptome whole blood GEO
- febrile illness bacterial viral RNA-seq blood GEO
- respiratory infection bacterial viral transcriptome blood RNA-seq
- sepsis viral bacterial whole blood transcriptome GEO

## Eligibility boundary

No candidate cohort should be scored before a feasibility audit confirms expression availability, identifier type, sample-level bacterial/viral labels and independence from GSE211567.
